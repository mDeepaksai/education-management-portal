# Education Management Portal

An AI-powered Education Management Portal built using FastAPI, Python, MySQL, SQLAlchemy, and Gemini AI.

The system manages students, teachers, courses, attendance, assignments, examinations, marks, academic analytics, risk analysis, performance trends, and personalized AI-based recommendations.
